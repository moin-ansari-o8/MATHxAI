# MATHxAI 🚀

## What is this website about?

MATHxAI is a place for curious minds who want to know what goes on "behind the scenes" of Artificial Intelligence. It explores the mathematics, the core concepts, and how it all works at scale. Built by a beginner, specifically for beginners, this project is designed to make complex AI topics feel approachable, intuitive, and playful. 

**"AI is not magic—it's Mathematics at scale."**

This project embraces a "Playful Illustrated EdTech" aesthetic to break down the complexities of machine learning and neural networks into interactive, easy-to-digest chapters. Instead of boring walls of text, you will find interactive playgrounds, visualizations, and fun diagrams.

## How to Contribute ✨

We absolutely welcome contributions! Whether you want to add a completely new chapter, improve an existing interactive lab, or simply fix a typo, we'd love your help.

To keep the project's quality and aesthetic consistent, please follow these rules when contributing:

### 1. Clone the Repository
Start by cloning the repo to your local machine and creating a new branch for your feature or chapter.
```bash
git clone https://github.com/moin-ansari-o8/MATHxAI.git
cd MATHxAI
npm install
npm run dev
```

### 2. Follow the Design System 🎨
This project uses a very specific "Neo-brutalist / Paper-themed" aesthetic. Before writing any UI code or adding new interactive components, you **MUST** read and follow the design guidelines outlined in:

👉 [`helpers/design.md`](helpers/design.md)

It contains everything you need to know about our colors (Ink, Sunshine, VioletPop, NeonPink, etc.), typography, heavy shadows, borders, and UI component tokens.

### 3. Adding a New Chapter 📖
Contributors are highly encouraged to add new chapters to the AI journey! To propose a new chapter:
- Create a new markdown file in the `data/` directory outlining your chapter's specifications. 
- Name it using the format: `chapter_NO_NAME.md` (for example, `chapter_03_learn.md`).
- Inside this file, thoroughly define the interactive components, the concepts being taught, and the topics you want to include.

### 4. Submit a Pull Request
Once you're happy with your additions, submit a Pull Request (PR) describing the changes you've made. I will review your PR and accept the changes if they are relevant, accurate, and fit the playful aesthetic of the project.
